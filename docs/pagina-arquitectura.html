1 · Arquitectura conceptual

Patrón agente con herramientas sobre una arquitectura desacoplada. El modelo generativo se usa solo para comprender lenguaje natural y redactar respuestas: la autorización, la ejecución de transacciones y el acceso a los datos quedan bajo control del middleware y del ERP. Esa separación es la que acota el riesgo de modificaciones indebidas.

Las cuatro barreras que atraviesa cualquier cambio, en orden. Ninguna es opcional.

    rect rgb(209, 250, 229)

        M-->>U: estado actual → cambio propuesto
        U->>M: Confirmar
    end

    M->>E: ejecutar cambio
    E->>E: OF_DETALLE.estado · SEGUIMIENTO_ETAPA
    E->>E: recalcular ORDEN_FABRICACION.estado
    E->>E: AUDITORIA · resultado OK · canal voz
    E-->>U: confirmación del registro
Confirmar, cancelar y rechazar quedan los tres registrados en auditoría. Cancelar no es «no pasó nada»: es evidencia de que el control funcionó.

Dos decisiones que se leen en el diagrama. ORDEN_FABRICACION no tiene cliente_id: el cliente se alcanza por PEDIDO. Y COMENTARIO_TALLER y SEGUIMIENTO_ETAPA cuelgan de OF_DETALLE, no de la OF — los comentarios y los cambios de etapa son por ítem, y el estado de la OF es derivado.

Lo que el modelo todavía no cubre

FaltaPor qué hace falta
AUDITORIA.resultado T-09 exige registrar «Usuario, Fecha, Acción, Resultado». Sin esa columna no hay dónde anotar un rechazo por permisos ni una cancelación.
AUDITORIA.canal / origen Sin ellos no se puede medir la adopción del asistente frente a las pantallas del ERP — que es la hipótesis a validar.
Transiciones entre etapas ETAPA_PRODUCCION no las modela. Haría falta una ETAPA_TRANSICION.

Construido · el prototipo navegable

  • React 18

    Las 7 pantallas. Estado por Context, sin librería externa: el alcance no la justifica.

  • Vite 5

    Build y servidor de desarrollo. base: './' para que funcione en cualquier subruta.

  • TypeScript

    Las interfaces replican el modelo de datos destino en snake_case, campo por campo.

  • Tailwind CSS

    Sistema visual con los tokens de color reales de brimec.com.ar.

  • React Router

    Enrutado por hash: recargar una pantalla interna no devuelve 404.

  • Lucide

    Iconografía. Única dependencia de interfaz más allá de React.

  • Web Speech API

    Dictado por voz. T-09 lo define como canal principal: el operario tiene las manos ocupadas.

Herramientas de soporte

  • Node.js 20

    Entorno de build y del banco de pruebas.

  • Python

    Generación determinista de los datos sintéticos y corrección de los .docx.

  • GitHub Actions

    Instala, corre los 41 casos, compila y publica. Si un test falla, no publica.

  • GitHub Pages

    Hosting estático con HTTPS — que el micrófono exige.

Propuesto para producción · nada de esto está conectado

  • LLM con tool calling

    Interpreta la intención y elige la herramienta. Proveedor por evaluar: precisión, latencia, costo y condiciones de tratamiento de datos.

  • FastAPI

    Middleware. Autenticación, RBAC, reglas, confirmación y auditoría. Única vía de escritura.

  • ERP SaaS (Odoo)

    Sistema transaccional: maestros, catálogo de etapas, reglas y auditoría. Dependencia número uno.

  • Base de datos

    Persistencia del ERP. El modelo nunca la toca: ni accede directo ni ejecuta SQL.

Los controles de permisos del prototipo corren en el navegador. Representan el flujo; no son un control de seguridad. Un usuario con la consola abierta podría saltearlos. Por eso T-10 insiste en que la autorización debe vivir en el backend.

6 · El límite honesto del prototipo

T-09 descarta la automatización por reglas por rígida. El prototipo usa reglas —pero tolerantes— y documenta dónde se rompen.
