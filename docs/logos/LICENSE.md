# Logotipos

Los archivos `.svg` de esta carpeta provienen de **[Simple Icons](https://simpleicons.org)**,
publicados bajo **[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)**
(dominio público). Se les agregó únicamente una regla de estilo para que tomen el color de marca
y se adapten al tema claro u oscuro de quien los mira.

Las marcas pertenecen a sus respectivos titulares. Se usan aquí de forma nominativa, para
identificar las herramientas empleadas en un trabajo académico.
